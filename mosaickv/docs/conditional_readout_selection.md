# Consumed-input conditional readout selection

This is a separately labeled precision-allocation variant, not a new quality
claim. Source SHA b9e2dff's actual final-layer engineering gate must pass on
both consumed inputs before GPU submission. Do not expand the cohort.

The seed retains individual prompt queries, the sparse evidence graph,
value-aware utility, lazy-greedy submodular selection, RoPE-neutral residual
prototypes, original exact protection, pinned CPU residuals and the validated
storage reader. Source replacement remains a common lossless codec, not
prototype compaction. All logical positions and original quantizer headers
remain unchanged.

At the first provisional update, reuse the original prefill and observe the
actual draft query and routed last-layer K/V. The original graph's neighboring
nodes followed by its value-utility ranking supply at most 16 unprotected
receiver positions. An attention-output surrogate shortlists at most four
single, one-head, equal-capacity substitutions. The surrogate cannot approve
a transaction. Donors are only the four additional exact rows; mandatory
rows and prototype memberships cannot be removed.

For at most ten candidate plans (identity, member restoration, four swaps,
and their restoration combinations), evaluate the real frozen final-layer
output projection, residual, RMSNorm, MLP, final RMSNorm and vocabulary head.
No later-layer linearization is involved. The conditional target restores
only this head's original prefill K/V at the SAME compressed draft state;
it is not global FullKV, oracle future queries, or benchmark ground truth.
Minimize KL to that conditional target, retaining the identity greedy token.
Identity wins non-improving ties. No model weights or gradients are updated.

The selected equal-capacity exact transaction updates existing buffers. If
original member restoration is selected, the real pinned residual payload is
promoted using the already charged GPU reservation and the current token is
recomputed once. This is a new **conditional-readout uncertainty policy**, not
evidence that the old entropy threshold triggered. Record the trigger and
do not describe controlled restoration as benchmark-quality recovery.

Separate exact-only, restoration-only and joint arms. Also disable forecast,
graph, value utility, submodular rewards and repair separately; no-forecast
must disable draft-readout allocation, not secretly retain it. All precision
arms use the same source replacement and 6,713 bytes of real auxiliary GPU
storage; the efficient parent and non-replaced controls have explicitly
different physical storage. Charge temporary readout tensors separately;
the decode counter does not certify whole-request KV peak.

Require actual selected logits to match the predicted conditional suffix
bitwise, unchanged 32-token KL <=0.02 / max-logit <=1 / token-agreement 1,
all 128 predictions, exact storage accounting, old source-owner retirement,
complete failed rows and manifests. Record the all-six-component ablation
honestly. Neither a local KL gain nor unchanged two-image CIDEr establishes
independent superiority, latency superiority, or every component's benefit.
