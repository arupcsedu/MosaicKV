# Bounded six-mechanism component ablation

This extends e2e1208 on the actual a6f689f storage execution path. It does not
modify the successful storage-only defaults or user paper. Only the SAME two
already consumed COCO inputs from storage-six-overlay-20261106-v2 are allowed.
References are absent from model-facing inputs. Caption scoring occurs only
after all plans and predictions are frozen, and cannot choose a candidate.

## Registered controls

Every component arm allocates the same real four-extra-exact, two-member
prototype, phase, index, work, promotion and flag tensors, plus pinned CPU
original residuals. The inactive parent-reserved arm retains those allocations
without reading their payloads. It is not a claim of efficient parent storage.
No fake tensor sizes or uncounted backing owners are used. Exact-members uses
the already charged promotion addresses, and is not called a repair event.

The full arm is compared with no forecast (observed prompt attention), no graph
edges, zero value/novelty weights, modular utility without coverage rewards,
no extra exact reads, original exact members instead of prototype reads,
disabled repair, and actual forced repair. All retain the original 128-token
generation, model revision, media, precision, eager implementation, seed and
mandatory policy. Each provisional probe is two predictions. Forced repair
must reproduce exact-members final logits bitwise.

Initial, final, and counter-peak backing bytes are checked separately for every
sample. If generated-history representation differs in cost, that point is NOT
called matched at that boundary. Original native KV owners must be retired.
The counter peak is not an independent whole-request KV audit.

FullKV is a separate quality reference. Save all trajectories and calculate
FP64 KL/logit/token diagnostics. After the first different greedy token, later
own-trajectory logits are not called shared-prefix comparisons. Supports with
different divergence points do not generate a paired KL-benefit conclusion.
Single timed calls with synchronized construction instrumentation are diagnostic,
not latency-superiority measurements. Reverse component order on worker 1.

The full arm exports only its routed head's original/constructor-reconstructed
K/V, post-RoPE prompt queries and phases to a hash-bound CPU evaluation artifact.
The temporary full-layer reconstruction is released before decode, and these
captures are not online residual caches or inputs to planning. CPU analysis
separates exact-only, prototype-only, joint and restored-member attention-output
errors on early/later prompt-prefix halves. These are causal local diagnostics,
not independent examples or generated-answer-quality evidence. Save all final
logits so analyzer corrections do not require GPU inference.

## Stopping and replacement boundary

Execution alone, graph coverage, or a changed selected-ID list is not a useful
model-level effect. Report negative, neutral and positive effects, and whether
they are consistent on both consumed images. A two-image local improvement is
not independent answer-quality evidence. Larger/fresh campaigns stay disabled.

A replacement precision design is conditional, not pre-approved by a successful
process exit. It must replace actual retained source data, count every new
metadata/repair/work allocation, preserve mandatory rows and original positions,
and demonstrate net backing-storage savings. The current source is shared
across heads; a per-head prototype cannot simply delete shared source codes.
CPU feasibility and actual owner-retirement tests must precede any new GPU
replacement diagnostic. Do not remove parent protections or expand routes
merely to make all six mechanisms appear beneficial.

## Finite execution

One immutable source commit, two one-A100 workers (12 CPUs each, 30 minutes),
and an afterany CPU analyzer. Existing admission controller limits aggregate
GPU use. No polling loop and no automatic new cohort are introduced. Raw
failures and saved logits are retained, and report provenance binds inputs,
source, model, environment, manifests and every trajectory hash.
