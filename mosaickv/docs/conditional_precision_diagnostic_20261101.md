# Conditional dense-body extrema (same consumed inputs, same bytes)

Preserve the complete negative inverse-phase/capacity study. No source-history
composition passed the saved-logit MM-Vet screen. The independent protected
projection-source CPU study is a different direction and does not authorize this
KV experiment or a promotion; do not pool them.

The current codec restores protected text, first-four/last-eight selected rows
and sparse exceptions after dequantization. But those exact rows still influence
the dense body's range. Removing them from range fitting can improve the useful
quantization interval without changing any selected or mandatory value. This is
an instance of established dense/sparse outlier separation, related to KVQuant,
not a novel general quantization principle or an official baseline port.

Frozen procedure, inherited from phase_capacity_diagnostic_20261031.md:

- Same two CONSUMED inputs, checkpoint/revision/BF16/eager, prompt/media/processor,
  128 greedy predictions, first-EOS scoring, 32-prefix guard and all controls.
- Same five methods, five arms, original own caps, ratio ladder 0.5/0.6/0.65/0.7.
  No changes to bit widths, reservations, selections, corrections or decoding.
- Apply conditional extrema identically to all methods' four recoded arms;
  retain the original shadow unchanged and bitwise checked.
- Derive the exact-row mask ONLY from actual head-local exact rows and actual
  TextSource projection slot metadata. Ignore scalar-only patches unless the
  entire row is independently exact; never exclude an unprotected scalar.
- For each quantization group substitute protected rows with an existing
  unprotected group minimum before calling the unchanged packer. Completely
  protected groups use finite zero representatives; exact overlays restore
  their complete original post-RoPE values. No new persistent mask or decoder.
- Raw current K/V, original logical positions, mandatory tokens and post-RoPE
  overlays remain unchanged. The mask/temporary work is a construction cost.
- Byte sizes must match the registered unconditional arm at initial/final/peak
  boundaries, at the same memberships and bits. This is a controlled numerical
  ablation within each method, not a claim of equal bytes across selectors.
- Guard remains max KL<=0.02, max logit difference<=1, greedy agreement=1 across
  the same 32 FullKV conditioning prefixes. No threshold relaxation, no draft
  token emission, no residual repair, prototypes or extra source history.
- Two one-A100/12-CPU workers <=30 minutes, full CPU suite first, finite afterany
  analysis. Keep all negative/unsupported rows. No fresh cohort, calibration,
  large campaign, frozen candidate or paper claim. Timing remains zero warmups,
  one repetition, fixed order: not evidence of a latency advantage.

Only a genuinely changed arm passing BOTH inputs' unchanged guard and not
regressing either anchor diagnostic ROUGE can justify further consideration.
Even that is not independent task-quality evidence; independent N=0.
