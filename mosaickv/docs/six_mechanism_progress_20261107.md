# Six-mechanism engineering outcome: superiority NOT established

This is an implementation/status record, not a paper-results report or an
independent confirmation. EviCastKV and MosaicKV identify the same system.
All new model diagnostics use already consumed examples. Preserve the validated
storage variant and every negative result. Do not promote these artifacts into
an original six-component compaction or universal baseline-superiority claim.

## What now works

- The precision-overlay variant invokes forecasting, the sparse evidence graph,
  value-aware utility, budgeted selection, actual exact/prototype/residual tiers,
  and real repair. The overlay is on one head in final layer 31. It is **not**
  the original multi-layer KV-slot compaction design.
- The source replacement actually retires the old code owners. Removing only
  globally protected zero-code rows preserves all 128 logit vectors bitwise and
  saves 37,381 and 57,769 bytes on the two consumed inputs, including the shared
  logical-row map. This is small, lossless codec hygiene, not prototype-member
  source retirement or a 30% improvement.
- Indexed positional edges, direct coactivation gathering and deterministic
  cutoff partitioning preserve graph hashes and model logits. Prototype-only
  construction skips an unused exact-block search rather than computing and
  discarding it. No scoring rule was silently changed by these optimizations.
- A private final-layer guard computes the actual storage-parent counterfactual
  suffix. The 16-input panel preserves all parent captions and all 128 greedy
  tokens. Every exported parent counterfactual matches the ordinary parent's
  logits bitwise. One of 2,032 updates required a safety veto.
- Live decision-risk repair really transfers pinned residuals, promotes original
  K/V and recomputes the current final-layer suffix once. The natural-event and
  disabled controls use identical storage. Stress/preloaded controls verify the
  mechanism, not benchmark-quality recovery.

The timing study uses five warmups and twenty paired timed repetitions per
input, balanced randomized order and 10,000 bootstrap replicates. Repetitions
of two fixed inputs are not independent benchmark examples. The two adjusted
upper ratio bounds support equal-or-faster execution only against the prior
hybrid. They do not establish a latency win over Prompt Top-K, PrefixKV,
VL-Cache or LOOK-M.

The source screens count the existing adjacent-layer lossless codec, offsets
and replay scratch, not just raw arrays. Independently minimizing raw layer
payload inflated net storage by disrupting code reuse. The corrected dynamic
program includes the parent at every layer and whole-stream raw fallback, so it
rejects those regressions. CPU source-array storage is not GPU active KV or
whole-request peak. No hypothetical reader/format is labeled operational.

## Why the remaining problem is architectural

One head's prototype cannot retire a projection input shared by all 32 heads.
The auxiliary exact/prototype/residual payload therefore adds memory unless an
actual source owner can be removed. The tested replacements did not provide a
useful net reduction after common coding costs.

There is also an intentional ceiling on the current safety design: when the
guard enforces the parent's greedy token at every step, induction on the emitted
prefix makes the entire answer equal to the parent. This is useful for safety,
but cannot itself produce a higher caption score. Better internal KL or a
successfully executed repair must not be presented as a benchmark-quality gain.
The current natural repair reduced KL but failed to recover the parent's token;
the safety veto, not the repaired cache, preserved the answer.

Forecast/graph/value/selection ablations did not show consistent marginal
caption gains. Source precision experiments preserve a source-MSE proxy; earlier
diagnostics already show why that does not guarantee autoregressive quality.
Do not increase sweeps or weaken model thresholds merely because CPU fit or
runtime correctness passes. Whole-request KV peak and independently validated
all-baseline quality remain uncertified. The registered source-format stopping
rule is reached; no fresh calibration or paper campaign is submitted.
