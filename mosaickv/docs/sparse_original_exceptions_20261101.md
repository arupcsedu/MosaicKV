# Bounded exact-exception diagnostic, consumed inputs only

Preserve prompt-only and four-step hybrid affine fitting as negative diagnostics.
Do not launch new cohorts, calibration or paper campaigns. The new intervention
does not refit any code or header: it adds sparse original-value precision
exceptions to the frozen successful source body. This tests a different error
mechanism without globally perturbing the quantizer.

Use only the same two consumed Description/MM-Vet inputs; independent N=0.
No annotation, teacher target, saved FullKV logits or benchmark score may enter
construction. Actual current FullKV prompt K/V are legitimate online inputs.
For LOOK-M, use its actual selected/merged K/V, not unmerged FullKV replacements.

Offer the identical correction policy to all four local baseline precision
adaptations and the shared-source precision variant. Preserve each constructor,
memberships, mandatory tokens, logical positions, original exact values and
raw append-only history. This is neither official baseline performance nor
the original six-component exact-selection algorithm. No prototypes, residual
CPU offload or decode repair are introduced.

First offer every corrected method the existing lossless minimum encoder:
store a minimum as BF16 only when expansion reproduces its original FP32 bits,
leaving the original FP32 scale and all quantized codes unchanged. This is not
the negative FP16 scale-rounding variant. Verify every actual CUDA layer's K/V
bitwise before adding exceptions. Record original and encoded parent bytes;
the recovered header storage can fund exact precision exceptions. This new
combined diagnostic does not promote or relax the earlier blocked standalone
minimum experiment or its registered parent-quality gate.

Freeze a maximum 1 MiB of extra exact exceptions per method, clipped to its
unchanged original physical cap and divided equally across layers. Each scalar
costs six actual bytes: int32 original-position index and BF16 exact value.
There is no uncounted tensor payload. Select the largest positive
importance*quantization_error^2 entries, with deterministic index-order cutoff
ties. Use the same post-RoPE diagonal sensitivity and equal 0.5/0.5 normalized
prompt/four-step-draft query families for every method. Do not choose budgets,
weights or exception limits by inspecting benchmark labels. The one-MiB limit
is an engineering allowance inside existing memory headroom, not a quality fit.

Capture the four draft steps once from the existing prefill, on private history,
and discard them before final decoding. Charge this forecast and the full parent
constructor to every corrected arm. Verify each GPU patch restores precisely
the intended original/merged BF16 scalars, changes no other scalar, and leaves
history sentinels untouched. Record patch count, measured bytes and local
weighted error removed; lower local error is not proof of better model quality.

Execute frozen source and four FP32 controls plus their five corrected arms,
with identical model, media, prompts, seed, generation, eager BF16 attention,
common transport, 128 timed tokens and complete 97/593 teacher targets. The
realized memories differ: explicitly do not call these byte-matched results.
Retain all failed/unsupported rows and immutable parent evidence.

Require raw retention-one bypass and complete teacher-forcing parity, source
retirement, immutable formats, private-state replay, and the unchanged 32-token
KL<=0.02, max-logit<=1.0 and greedy-token equality guard. PPL and FullKV-reference
ROUGE-L must each be no worse than the frozen source on both inputs for a
positive source diagnostic. No numerical relaxation or silent fallback.

Record initial/final/lease-inclusive decoder-owned peak backing for generation
and teacher forcing, extra exceptions, auxiliary draft tensors, and constructor
time. Whole-request/construction peak remains uncertified. Single fixed-order
timings are exploratory, not established end-to-end superiority.

One CPU suite, two one-A100/12-CPU/30-minute workers, and finite afterany CPU
analysis only, within the six-A100 aggregate maximum. A positive same-input
diagnostic still cannot establish independent quality or universal superiority.
