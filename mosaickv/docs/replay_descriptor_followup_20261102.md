# Private replay descriptors: bounded engineering follow-up

Only the same two consumed LLaVA inputs and source-precision/storage variants;
independent quality N is zero. No model or selection change, new examples,
quality campaign, prototype, residual repair or paper promotion.

First let the paired original/carried full-request diagnostic and its single
conditional dispatch attempt finish. An afterany watcher follows only newly
published job IDs, including the terminal closeout callback, with at most five
transitions and no repeated scheduler/log polling. Incomplete/numerically
unsafe parents block this follow-up. A parent no-slower engineering pass makes
it unnecessary. All four EviCastKV original/carried phase traces must otherwise
show >=0.10 seconds exclusive host replay work before GPU submission.

The intervention prepares immutable FORMAT DESCRIPTORS once per PRIVATE
request. Original compressed code packets, exact headers, corrections, logical
positions, selection memberships and weights remain unchanged. Every actual
compressed layer still executes its original byte decoder in its original
order; no decoded tensor is memoized across layers or tokens. Prepared formats
refer only to the already charged raw payload or one existing private replay
buffer per role. There is no new CUDA allocation, offload, quantization or KV
copy. Per-packet headers remain the same objects. Raw restarts and varying code
lengths retain their original semantics; returned codec destination identity
and shape are checked. Foreign/out-of-order indices fail explicitly.
There is one additional private Python descriptor per layer and a bounded
CPU binding list. They alias already charged GPU buffers; no CPU residual KV
is introduced. Record setup work as well as decode savings so work cannot be
hidden outside the end-to-end boundary.

CPU controls cover multiple cycles, bit identity, unchanged backing inventory,
no eager decoding, descriptor construction independent of decode-token count,
raw/length restarts, and disjoint request scratch. Synthetic GPU controls
exercise the real byte kernels for 32 layers and three cycles before model
inference. They are not benchmark-quality observations.

Freeze the common original/carried reader from the parent's paired decision.
Retain compiled dispatch reuse only if the parent's own adjusted end-to-end
improvement gate passed. Both modes use the SAME frozen reader and dispatcher.
Then compare original descriptors against prepared descriptors, randomized
within method/trial, five warmups and twenty repetitions, on EviCastKV and the
local PrefixKV adaptation. No hidden environment switch: explicit request and
plan booleans identify the candidate. Numerical and independently audited
initial/final/declared decode-owned peak parity are required for all five
adaptations and BOTH modes before timing. The codec is offered identically;
methods that declined unprofitable layer-code compression have zero descriptor
activity, explicitly recorded rather than fabricated. All measured timing
counter endpoints remain paired to their separate audited companion hashes.

Promote only if the Bonferroni-adjusted upper end-to-end ratio is <=0.99 on BOTH
inputs against the same-method original descriptor path. Otherwise stop. If
promoted, run the existing all-five-method request benchmark and <=1.05x
engineering similarity gate, reporting the stricter <=1.0 no-slower result
separately. Neither gate establishes statistical benchmark-quality superiority.
One descriptor candidate, at most two simultaneous one-A100/12-CPU workers,
sixty-minute worker limits, no new cohorts and no larger quality campaign.
Whole-request GPU peak remains uncertified; the exact audited cache boundary
must not be relabeled as that broader memory boundary. All caches use scratch.
