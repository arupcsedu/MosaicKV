# Explicit component admission, not six-stage relabeling

The November 7 user request allows dropping modules whose overhead does not
produce useful effects, after testing better uses. Preserve all full-method
and ablation implementations. The source dictionary screen tests a different
all-consumer prototype role. This independent optimization addresses the
currently justified parent-preservation path.

`component_scope(mode="storage_preservation")` requires an explicitly disabled
overlay and the bitwise source-only objective. It installs **no** overlay
constructor, materialization, cache-accounting, repair or model-run hooks.
The parent reader's validation and physical-storage accounting remain. Its
record lists all six inactive research overlays; it cannot be described as the
full six-component method or an independent quality improvement.

`mode="experimental_overlay"` still runs the complete existing implementation
and its controls. Invalid modes, enabled lossy overlays under a source-only
label, or unverified source-compaction transforms fail explicitly. Nothing
changes the default reader, the 256-image evidence, or original model math.

The new finite benchmark compares three arms, using the same common source
codec in every arm: current storage with inactive wrapper hooks, the hook-free
source-only variant, and the retained full-head-guarded hybrid. Six warmups,
24 balanced randomized paired trials, 128 predictions and unchanged BF16 eager
controls use only the two consumed COCO timing identities. Every vocabulary
vector must match the frozen appropriate parent/hybrid artifact bitwise.
Source-only arms must match initial/final/decode-owned peak backing exactly.
Record the hybrid's extra storage; this is component-elimination engineering,
not a byte-matched selection-policy or new all-baseline comparison.

Two one-A100/12-CPU workers use 30-minute limits and a six-A100 aggregate
controller. An afterany CPU analyzer preserves failures and uses 10,000 paired
trial bootstraps with six-comparison Bonferroni adjustment. Equal-or-faster
requires the adjusted upper ratio <=1.00; a 4% win requires <=0.96. Repetitions
on two images cannot establish independent quality or broad latency claims.
No larger cohort or paper campaign is submitted automatically.
