RMSNorm GPU job runs, followed by its CPU analysis and the independent BF16
source diagnostic. The metadata continuation can run concurrently because it
uses no GPU/model and cannot affect selection. Each producer has an `afterany`

acknowledgement. If the inventory analyzer is definitely rejected, the final
CPU callback may perform that already-registered aggregation after the known
workers finish. An uncertain acknowledgement remains blocked pending scheduler
reconciliation. Missing artifacts and CPU failures produce an explicitly partial
or blocked packet, never a completion pass.
