# Complete-owner source replacement: bounded development protocol

Keep the validated storage-only variant and all six research mechanisms. Neither
the dictionary nor Gray formats receives additional GPU work. This separately
labeled **common storage** optimization does not claim those six mechanisms
improve quality. The existing source quantization remains unchanged; coding is
lossless relative to those source bits, not a claim of unquantized FullKV state.

## Ownership and representation

Each original source serves both projections of all 32 heads. Every accepted
replacement encodes every original position and feature. Headers, exact values,
projection weights, RoPE, logical positions, numerical patches, and append-only
generated history are unchanged. No per-head overlay, offload, discarded evidence,
learned parameter, new quantizer, or benchmark-label fitting is introduced.

For corresponding original 3-bit codes in adjacent layers, test the reversible
residual `r = (current - previous) mod 8`. Decode with
`current = (previous + r) mod 8`. A subtraction can concentrate near-zero integer
changes which XOR disperses across several patterns. Use the existing exact
two-symbol palette, exception bitmaps, residual literals, and raw-group fallback.
This is conventional predictive coding, not a novel attention-selection claim.

The CPU screen also reports four bounded local predictors (lag one/eight, XOR
or subtraction, resetting every 128 symbols). They receive no GPU implementation
unless separately admitted. Their dependencies fit inside the existing 512-symbol
decoder block; no geometry, video layout, or extra halo is inferred.

Charge complete payloads, uint32 offsets, one actual GPU format selector per
layer, and the full existing replay scratch. The new selector replaces—not
supplements—the old selector. Each native program reads and writes only its own
192-byte source block, allowing in-place predecessor replay without another
decoded source owner. Reject aliases with immutable payload storage. Raw source
fallbacks remain real, charged owners; do not claim they were retired.

## Preregistered finite progression

1. CPU synthetic regressions cover exact bit roundtrip, corruption/dependency
   failures, complete consumer coverage, deterministic storage selection, actual
   offset/selector accounting, owner lifetime, and block-local replay semantics.
2. Two CPU workers inspect all 32 layers of each already consumed Description/
   MM-Vet source capture. Test every fixed predictor, preserve every outcome.
   Select only additive or common coding for native progression. Require at least
   **2% lower complete source stream plus replay storage on each input**; never
   equate this CPU measurement with measured GPU KV memory.
3. Only a complete positive CPU gate submits two one-A100 workers. Each first
   validates native packet bytes against the CPU oracle, bitwise reconstruction,
   in-place replay, isolated destinations, and original-owner retirement.
4. Each then tests common storage-only versus the same storage-only path with
   additive replacement on the two already consumed COCO timing inputs. Pinned
   LLaVA-1.5-7B BF16 eager, 128 predictions, five warmups and 20 balanced randomized
   paired trials. Every vocabulary vector must match the frozen parent bitwise.
   Require lower initial/final/decode-owned peak storage, no fallback, complete
   provenance and no new persistent replay allocation.
5. Use 10,000 paired-trial bootstrap replicates with two-input multiplicity
   correction. Equal-or-faster requires adjusted upper new/parent ratio <=1.00;
   <=1.05 is a trade-off, not a pass. No 4% win unless upper <=0.96.

Every dependent analyzer uses `afterany`, preserves failures, and writes once.
At most two one-A100 workers here (12 CPUs, <=45 minutes each), below the aggregate
six-A100 validation limit; register the common admission controller. No continuous
log polling, fresh cohort, calibration, or paper campaign is submitted. Negative
screens stop the corresponding GPU branch without weakening thresholds.

## Limits and later work

This test can establish a complete-owner representation improvement and parent
computation preservation on consumed inputs. It cannot establish new caption
quality, six-mechanism superiority, or superiority over all baselines. Whole-request
KV peak remains uncertified; construction temporaries must not be hidden behind
decode-owned counters. A positive engineering gate is a prerequisite—not permission
or evidence—for an independently frozen quality and whole-request memory study.
Common coding must be available identically to compatible baseline transports.

## Frozen follow-up after the first measured latency miss

The first complete-owner benchmark preserved all 128 logits and saved about
1.22--1.23 MiB per input, but was 0.27--0.29% slower. Keep that result negative
for the strict latency gate. Do not alter source precision, selection, budgets,
or thresholds. Fuse the parent and additive counts in one source read/kernel,
batch their prefix sums, synchronize once, and pack only the identical winner.
Native packet bytes must still match the CPU oracle exactly. Reuse the positive
CPU screen only after verifying its code bytes and all bound artifacts unchanged.

Add one separate tensor-result-audited decode call per arm after timed trials.
It is excluded from timing and must reproduce every frozen logit. Distinguish
audited decode peak, timed counters, whole-process allocator peak, and the still
uncertified whole-request KV-only peak. None may be silently substituted for
another. No larger or fresh quality campaign is authorized by this follow-up.

## Fixed-predictor and packed-word alternatives

The first partial operator attribution found redundant format search adds
encoder work; available CUDA traces also showed the 2-D prefix scan is not free.
Test a separately labeled fixed additive predictor with raw fallback. It omits
the parent search entirely, including on the first raw source layer. It can lose
some local compression versus best-of-three; compute its complete CPU cost from
the already-saved additive proposals, not their minima with the parent. Retain
the same 2% admission threshold. Parent costs not computed online must be null,
never invented zero savings. Actual paired cache storage supplies the comparison.

Separately test packed 24-bit predecessor arithmetic with per-three-bit carry
guards. All 64 symbol pairs in all eight lanes and random neighboring fields
must match exact modulo-eight arithmetic. No code format, quantizer, source
position, projection, or storage owner changes. This decoder optimization must
be applied to both common and additive methods in any comparison using it.
Defaults remain unchanged and no native capability is inferred from CPU tests.

Use only the verified consumed COCO source archives for the timing-only operator
matrix (common, searched additive, direct additive; bitmap and packed decoders).
Prior profiler activity gaps remain missing—not zero kernel cost. Do not repeat
model inference to recapture valid archives, and do not extrapolate operator
stream intervals into measured full-request latency. Choose any next bounded
model verification from this engineering evidence, never benchmark answers.
