extension checks seven writer candidates from six original freeze jobs using
already captured accounting, archived batch scripts and exactly 55 startup

historical-code execution is needed.

freeze-job ID to the saved accounting identity, exact clean startup revision,

repository tree are pinned. Complete argv validation distinguishes intentional
negative-analysis exit 2 from an argument-parser failure. V88's wrapper maps
