# Evidence refinement V14

These bounded controls extend V13 without modifying its immutable workers or
the production cache policy. They do not turn consumed diagnostic inputs into
fresh benchmark evidence. The historical lossy source and the distinct lossless
BF16 source must retain separate labels, accounting and numerical results.
The current lossless source control supports the audited full-MHA LLaVA path;
it must not be advertised as validated for grouped-query models whose input
activation can exceed their native K/V storage.

The media follow-up separately downloads only the four public, already pinned
InfographicVQA validation files (266,457,648 bytes), then hashes their images
alongside the other registered historical provider pools. No benchmark column
is decoded by that download stage. Dataset availability is not historical
exposure evidence: six early video-pilot campaign directories are missing, and
a completed later video row has a dirty-source fingerprint but no retained
frame/body journal. Cached videos alone do not certify those historical frames.
Those gaps remain explicit; neither a new download nor hash absence resolves
them.

## 1. Narrow historical derived-artifact proofs

The V12 frontier-2 inventory retains 25,266 errors. Its source-bound recovery
overlays already resolve some occurrences; raw error count is not the count of
unresolved scientific gaps. A read-only audit identified 588 `edges.parquet`
and 587 `raw_marginal_terms.parquet` occurrences as candidates for further
proof, not automatically resolved files.

Each admitted proof must authenticate the immutable worker record, mechanism
audit, artifact digest, exact recorded producer commit, reviewed producer AST
and closed footer schema. Internal cache-block IDs must be shown to be internal
through that producer's types and writer, not guessed from a numeric column.
Every original error remains intact. Missing provenance, altered schemas,
unexpected identity fields, symlink escapes and unsupported producers remain
unresolved. This finite overlay is not a waiver for arbitrary Parquet or JSONL.

## 2. A separate KV-specific whole-request boundary

Historical attribution combines cache storage with language-attention
workspace. It cannot be renamed KV-only or corrected by subtracting phase
maxima. The refinement therefore produces independent event-time metrics:

1. Persistent KV representation and cache-metadata backing.
2. The same backing plus cache-specific constructor, reconstruction, reader,
   history and auxiliary validation/demand-capture workspace.

Validation/demand workspace is conservatively included in metric 2 and also
reported separately. Query projections, attention scores, probabilities,
contexts and ordinary model activations may be excluded only through explicit
source-reviewed generation evidence. Unknown allocations remain in upper
bounds; inherited broad roles are not trusted. Mixed-use backing is counted
once in full across its lifetime unless a separately certified ownership
transition exists. Use actual `free_completed` order and address generations,
not sums of observed phase peaks.

A certificate requires complete request coverage, complete unoverwritten
events, immutable source/trace/owner/snapshot bindings, and exact attribution or
provably equal lower and upper peak bounds. Opaque non-PyTorch/vendor/device
allocations and allocator-reserved HBM remain outside this named boundary.
The original broad report is preserved. A certificate for the lossy source
does not certify a different streaming/lossless candidate or baseline.

## 3. Matched-representation construction timing

Only after V13's actual streaming lossless model gate passes may a bounded
paired diagnostic compare streaming and nonstreaming construction of that same
lossless representation. Both arms retain all original prompt positions,
weights, K/V, logical positions, history policy and fixed-prefix decoding.
This is an engineering comparison, not a comparison with the nearest published
baseline and not a benchmark-quality confirmation.

Preflight must establish independent native prompt-K/V and logit parity,
unchanged 32/128-prediction guards, private states, mandatory positions and exact
constructed initial/final bytes. Decode-owned peak comparisons require the
same audited tensor boundary; uninstrumented snapshots cannot be relabeled as
audited peaks. Any mismatch blocks timing.

Use five warmups and twenty paired repetitions in frozen randomized order on
each consumed input. Keep constructor all-word checks. Disable optional
per-operator audit/profiling identically in timed arms; independent numerical
controls and CPU reference copies belong outside timing. Include actual media
preparation, prefill, source construction, decoding and retirement in request
wall time. Report CUDA intervals as intervals including host gaps, not pure
kernel time; retain every wall/thread-CPU/CUDA observation. Keep strict
equal-or-faster acceptance separate from the reported five-percent-slower
trade-off. No allocator envelope is an exact KV-only peak certificate.

Each GPU worker uses one A100 and twelve CPUs; at most two timing workers are
admitted, with at most six aggregate project A100s. Canonical source and CPU
gates precede execution. Fresh confirmation and paper-scale experiments remain
blocked until their own complete provenance and empirical gates pass.
